## ✦ Sobre o projeto

Este projeto é meu portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e minha evolução como desenvolvedor Front-End.

A proposta do site é unir **código, estética e funcionalidade**, criando uma experiência visual moderna, minimalista e responsiva.

O projeto foi desenvolvido com foco em:

- Design minimalista e moderno
- Experiência do usuário
- Responsividade
- Animações e transições
- Organização do código
- Performance
- Adaptação para diferentes tamanhos de tela

## 📱 Responsividade

Um dos principais objetivos do projeto foi garantir uma experiência consistente independentemente do dispositivo utilizado.

O layout foi adaptado para:

- 🖥️ Desktop
- 💻 Notebook
- 📱 Smartphones
- 📐 Diferentes resoluções e proporções

A estrutura utiliza **CSS responsivo**, `media queries`, unidades relativas e layouts flexíveis para adaptar os elementos conforme o tamanho da viewport.

### Desktop

O layout aproveita o espaço horizontal para apresentar as informações de forma mais ampla.

### Mobile

No mobile, os elementos são reorganizados para facilitar a leitura e a navegação, mantendo a hierarquia visual do projeto.

---

## 🎞️ Animações

O projeto utiliza animações para tornar a navegação mais dinâmica e proporcionar uma experiência mais interessante ao usuário.

Entre os recursos utilizados estão:

- Animações de entrada
- Transições entre elementos
- Efeitos durante o scroll
- Microinterações
- Animações de carregamento
- Efeitos de hover
- Animações utilizando GSAP

As animações foram utilizadas com o objetivo de complementar a interface, evitando que fossem apenas elementos decorativos.
